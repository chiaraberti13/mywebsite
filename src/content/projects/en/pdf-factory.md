A pipeline that automatically generates product datasheets as **PDFs in 6
languages** from an Excel file and publishes them online.

Built in **Node.js** with an HTML/CSS → PDF approach, including image
optimisation, secure credential management and regression testing. Execution
runs via **cron** on a dedicated, protected virtual machine.

It modernised a previous legacy component, making the process completely
automatic and repeatable.

## My contribution

Analysis of the pre-existing system, design of the new solution and definition
of the automation flow. I selected the technology stack, structured the
multilingual handling and defined the main security and reliability measures,
following the transformation from a legacy solution to a fully automated
system.
