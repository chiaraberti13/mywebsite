TetraEarUbuntu provides a reproducible environment for running **TetraEar**
with **RTL-SDR** hardware on Ubuntu, Debian and Windows.

### Main features

- Guided installation of dependencies, Python environment and codecs.
- RTL-SDR chain configuration.
- Environment diagnostics and repair.
- Tools and documentation for authorized TETRA signal analysis.

### Architecture

**Python** automation and system scripts coordinate components and
dependencies, reducing the common failure points of manual setup.

### My contribution

Installer development, pipeline integration, diagnostics, compatibility fixes
and documentation. The accurate category is **SDR & radio**: the project is
about signal reception and analysis, not penetration testing.
