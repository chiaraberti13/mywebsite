An application for designing a custom system online and obtaining a detailed PDF quotation in seconds, sent by email and automatically routed to the local sales representative.

It includes automatic component and luminous output calculations and the generation of the system diagram.

Developed in PHP with a modular architecture, multilingual support (IT / EN), and application security: CSRF protection, input validation, and secure credential management.

### Personal contribution

Design of the modular architecture, definition of the calculation logic and security measures, and setup of the testing workflow.
