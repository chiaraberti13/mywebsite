A pipeline that generates product datasheets as PDFs in 6 languages from an Excel file and automatically publishes them online.

Developed in Node.js using an HTML/CSS → PDF approach, image optimization, secure credential management, and regression testing.

Generation runs automatically through cron on a dedicated, protected virtual machine, without manual intervention. It modernized a previous legacy component, making the process fully automated and repeatable.

### Personal contribution

Analysis of the existing system, design of the modular architecture and multilingual system, and selection of the technology stack and security measures.
