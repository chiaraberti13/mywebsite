An Ubuntu-based environment designed to make a **TETRA** reception and analysis
chain easier to install, operate and reproduce.

### Main features

- Guided installation of the required components.
- Startup and configuration management.
- Environment diagnostics and troubleshooting tools.
- Documentation focused on authorized use and research.

### Architecture

**Python** utilities coordinate configuration, checks and startup across the SDR
toolchain on Ubuntu.

### My contribution

Installation-flow design, configuration automation, diagnostics and
documentation. The project integrates open-source components and preserves the
**GPL-3.0** licence.
