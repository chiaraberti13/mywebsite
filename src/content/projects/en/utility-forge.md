A collection of standalone, **privacy-first** utilities for processing
documents, images and files without relying on external cloud services.

### Included tools

- EPS barcode generation and PHP image conversion.
- Privacy and metadata analysis, document redaction and sanitization.
- PDF tools plus batch file renaming and organization.
- Local-first processing.

### Architecture

A **JavaScript** repository organized as a collection of separate tools: each
utility keeps a focused purpose and can evolve without adding weight to the
others.

### My contribution

Concept, development and consolidation of the tools into a coherent space. The
accurate category is **automation & utilities**; privacy and security are
cross-cutting characteristics rather than the project's sole domain.
