A web app that generates **EAN-13 barcodes in vectorial EPS format** from an Excel
of product codes: load the file, press a button and get all the barcodes in a
single ZIP. Built for packaging and retail work that requires dozens or thousands
of codes.

### How it works
Double-click the HTML file → load Excel/CSV (code + barcode columns) → "Generate"
with progress bar and stats → single download or one **ZIP**. Each code becomes a
vectorial `.eps`, scalable without quality loss.

### How it's built
A **single HTML file** (HTML + CSS + JavaScript), zero install, works **offline**.
The **EAN-13 encoding is implemented from scratch**: L/G/R tables, first-digit
parity patterns, Modulo 10 check digit (GS1 / ISO/IEC 15420). The **EPS/PostScript
rendering** is generated by hand (bars, guard bars, Helvetica text, quiet zone,
BoundingBox) and is compatible with Illustrator, CorelDRAW, Inkscape and Affinity.
Batch generation in async chunks keeps the UI responsive.

### Privacy
All processing happens **in the browser**: commercial data never leaves the
computer. No server, no tracking, no account.
